# Interactsh: Out-of-Band (OOB) Testing Server

## Overview
Self-hosted alternative to Burp Collaborator for blind vulnerability confirmation: Blind SSRF, Blind XXE, Blind SQLi, and Log4Shell.

- **Default Port / Access**: `8090 (HTTP), 5354 (DNS)`
- **Directory**: `Classes/02_web_penetration_tester/20_21_24_server_side_ssrf_xxe_ssti/oob_interactsh`

---

## How to Solve & Practice

1. Start the server: `docker compose up -d`.
2. Run the client to listen for incoming callbacks in real time: `docker run --rm -it --network host projectdiscovery/interactsh-client:latest -s 127.0.0.1:8090`
3. Copy the unique callback domain generated by the client.
4. Inject the callback domain into target input fields (e.g. `http://<your-domain>:8090/callback` in SSRF parameters or XXE XML entities).
5. Observe DNS and HTTP callback logs in the interactsh-client terminal.
