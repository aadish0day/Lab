Lab Briefing & Objective
Vulnerability: JWT 'jku' Header Injection

This lab uses a JWT-based authentication mechanism where the server blindly trusts the jku (JWK Set URL) header parameter specified inside incoming client tokens.

🎯 Target Objective: To solve the lab, modify your session token with a jku header that points to your exploit server, access the admin panel, and delete the user carlos.
Attack Workflow:
  1. Log in to your account using the credentials wiener:peter and inspect your session token on the My account page.
  2. Notice that the token's header contains a jku parameter pointing to http://victim-app:5000/.well-known/jwks.json.
  3. Navigate to the Exploit Server (port 6000) to generate an attacker RSA keypair and host your public JWKS at /evil-jwks.json.
  4. Forge a token with payload sub: administrator (or role: admin) and header jku: http://attacker-jwks:6000/evil-jwks.json, signed with your attacker private key.
  5. Access /admin with your forged token and click Delete user carlos to solve the lab!
